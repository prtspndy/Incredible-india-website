# Incredible India — Modern Bootstrap Website

A redesigned multi-page Indian culture website built with:
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Small vanilla JavaScript enhancement layer

## Pages
- `index.html` — Home / overview
- `culture.html` — Festivals, attire, languages and dance
- `landmarks.html` — Monuments, landscapes and states/capitals
- `cuisine.html` — Indian food showcase
- `contact.html` — Contact form UI

## Assets
The `assets/images` folder contains the images supplied for the original project.
`assets/graphics` contains locally-created SVG decorative graphics.

## Run
Open `index.html` in a browser. Bootstrap and Bootstrap Icons are loaded from jsDelivr, so an internet connection is needed for those CDN assets.

## Notes
The contact form is intentionally front-end only. The JavaScript prevents a real submission and displays a success message. Connect it to your preferred backend/email service when deploying.
