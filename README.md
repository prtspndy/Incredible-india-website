# Incredible India

A simple static Indian Culture & Heritage blog/awareness website.

## Tech
- HTML5
- CSS3
- Bootstrap 5 CSS via CDN
- No JavaScript, backend, database, authentication, or build tools

## Entry point
Open `index.html`.

## Pages
- `index.html` — Home
- `culture.html` — Culture
- `heritage.html` — Heritage
- `cuisine.html` — Cuisine
- `traditions.html` — Festivals & Traditions
- `about.html` — About
- `contact.html` — Contact

The contact form is intentionally static and has no backend processing.
